mbgapp

Last updated: 2026-10-30

mbgapp is a small personal tool built on rclone that copies files from the owner’s own Google Drive folders to the owner’s own computer. It is made for personal use by a single person, runs only on that person’s hardware, and is not offered as a service to anyone else.

The source code is published on GitHub at github.com/jordi-monmany/mbgapp.
